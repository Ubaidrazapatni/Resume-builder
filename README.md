# 📄 Resume Builder

A responsive resume builder web application built with **HTML, CSS and TypeScript**.

The project is designed to provide users with a simple and user-friendly way to create and present a professional resume.

## ✨ Features

* 📄 Resume creation interface
* 👤 Profile information section
* 📝 Resume content sections
* 🎨 Clean and responsive design
* 📱 Responsive user interface
* ⚡ Interactive functionality using TypeScript

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **TypeScript**
